## 建议阅读顺序

1. 参数与训练：区分架构配置、可学习参数、数值表示和推理时的状态。
2. Transformer 内部计算：理解张量、Token、嵌入、QKV、注意力、多头、多层与 FFN。
3. 完整生成流程：从输出头选 Token，到 Prefill、Decode 与 KV Cache。
4. 模型工程：读结构代码，理解架构取舍、文件大小、浮点精度与量化。
5. 发布模型：对照 Qwen 的配置、权重、分词器与加载示例。
6. 模型应用：理解 BERT、FinBERT、BioBERT、搜索排序与 M6。
7. 复习巩固：按问答归档、公式速查、术语表和分组自测检查理解。

本地校验：`python3 scripts/lint.py`。正文、索引、首页和日志在同一次提交中更新。

公式使用 LaTeX，流程图使用 Mermaid；GitHub 可直接阅读。教学用数字不代表真实模型内部权重；参数规模、许可及产品信息均需结合具体版本与核对日期理解。
